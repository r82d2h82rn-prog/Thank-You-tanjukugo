## 実装した分析機能

許諾根拠・SHA256・年度・学部・方式等が揃うローカル資料だけを処理。本文・設問・出典英文の断片は出力せず、候補熟語の文字位置のみを記録。再配布の許可と分析の許可を別に扱う。ローカル資料はanalysis/private/へ置けばGitから除外される。

明示した語形辞書によりdevelop/developed/developingを集計でき、派生語developmentを混ぜない。候補語について総数、1万語あたり頻度、大学/年度/試験の広がり、大学別・学部別・年度別、大学ごとの語数で正規化した平均をCSVへ出力。未取得の大学を母集団に加えない。

熟語はgive/gave、give it upのような変形を候補検出する。最大3語の挿入までを許す単純な限定探索で、文境界・語義・同形語の曖昧さや複雑な構文変形は人手確認が必要。自動の候補数を確定頻度にしていない。現段階では高度な形態素/構文解析、全語形、専門的な入試統計の検証は未実装。
