# 初期Web版の検証記録

2026-11-11（日本時間）。今回は追加指示の「Web版の基礎」を優先し、最終仕様は `FINAL_SPEC.md` に保存。詳細な実装範囲・制限・起動手順はREADMEを参照。

## 実行環境と結果

- Node.js 24.22.1 / npm 11.9.0 / Expo SDK 55 / React 19.2 / React Native 0.83.10。
- `npm run typecheck`: 成功。
- `npm test`: 6件成功。教材150件と選択肢3,000組の検証を含む。
- `npm run test:e2e`: Chromiumで3件成功。選択式30回答・記述式20回答で両形式の独立性を確認。別ケースで熟語3語入力、お気に入り、一覧スクロール復帰を確認。
- `npm run build:web`: 成功、静的配信用distを生成。
- `npm run test:production`: 成功。静的ビルドに検証スイッチが存在しないこと、Web Audioの実ノードでタップ・正解・不正解音が起動すること、画面の実行時エラーがないことを確認。
- 390px幅で横方向のはみ出しがないことを確認。E2Eと本番確認で画面キャプチャを生成（`test-results/`、Git管理対象外）。

## 修正した問題

一覧から詳細へ遷移する際のコンテンツ縮小によるscrollイベントで一覧位置が上書きされる問題を修正。遷移前の位置を保持し、レイアウト更新後に復元するようにした。実際に後半の熟語を開いて戻るテストが成功。
