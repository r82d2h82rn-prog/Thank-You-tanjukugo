# 長文読解LEVEL1

2026-11-12。ユーザー指定に従い「ホーム」と「検索」の間へ「長文読解」を追加。押すと読解専用のLEVEL1〜4選択が開く。単熟語のLEVEL画面から長文枠を取り除いた。

## 教材と利用範囲

LEVEL1は独自制作100題・300問・合計16,342語。各本文150〜250語、各3問の四択。内容一致、語句空所補充、文・節空所補充、主題、指示語、推論、文挿入、段落整序、要約、語句の意味推測を各10題。日本語訳、設問ごとの正解・誤答理由と引用根拠、語句注、構文の記号・色・文法説明を持つ。段落整序は結果で正順に表示する。

無料では各LEVELから好きな3題を選択し、変更不可の確認後に永久解放する。キャンセルでは枠を使わない。残り97題はPremium対象で、開発用Premium検証モードでは確認可能。本番の購入処理と権限付与は引き続き未実装。LEVEL2〜4の教材は未制作。

本文と設問は別々のスクロール位置を保持し、タブを往復しても提出前の回答を保持。下部バーで別画面に移った間は時間を一時停止。時間制限なし、目安超過後も解答可能。全問の回答後にまとめて採点し、二重提出を防ぐ。途中で一覧へ戻る場合は回答破棄を確認する。未提出セッションはページ再読み込みでは復元しない。

初回・最高・直近の正答数と実測時間、試行数を既存の保存キー/version:1のoptional readingに保存。最高は正答率、同率なら短い時間で比較。旧単熟語データは変更・削除しない。保存範囲は同じ端末・ブラウザ・オリジン。無料解放の「永久」はこの保存範囲での継続利用であり、クラウド同期や削除後復元は未実装。
