# Thank You単熟語長文3900+｜総合開発指示書・改訂版

## 0. 開発目的

英語学習アプリ **「Thank You単熟語長文3900+」** を開発してください。

英単語3,900語・英熟語2,000個・長文400題を収録する、Google Playでの商用配信を目指したアプリです。

最初はスマートフォンとChromebookで試せるWeb版を制作してください。企画書だけではなく、実際に操作できるプログラムを実装してください。

今回の初期開発では検証用教材を用い、学習機能・試験・データ保存・画面操作を先に完成させます。全教材の本格制作とGoogle Play公開は、その後の段階で進めます。

**最重要事項：選択式と記述式の習得状況は完全に独立させてください。共有してはいけません。**

## 1. 開発構成

- React Native + Expo + TypeScript
- Expo WebによるWebアプリ
- GitHubによるソースコード管理
- VercelによるWeb版公開
- Supabase AuthとPostgreSQLによる認証・データ保存
- 端末内キャッシュと再同期
- 将来のAndroid向けEAS Build対応
- モバイルファーストのレスポンシブUI

既存の別プロジェクトに変更を加えず、適切な新規リポジトリで管理してください。

必要な外部サービス接続・秘密情報・権限が不足する場合は、その部分を勝手に実行せず報告してください。

## 4. 最重要：習得状況の完全分離

**選択式と記述式では、それぞれ別の習得状況を持ちます。**

単語・熟語の各項目について、次の情報を別々に保存してください。

### 選択式

- 選択式の習得済み／未習得
- 選択式の連続正解数
- 選択式の学習履歴

### 記述式

- 記述式の習得済み／未習得
- 記述式の連続正解数
- 記述式の学習履歴

### 習得条件

どちらの形式も、**同じ形式で2回連続正解すると習得済み**になります。

ただし、形式間で正解数を共有しません。

例：

- `develop` を選択式で2回連続正解 → 選択式のみ習得済み
- 同じ `develop` を記述式で1回正解 → 記述式はまだ未習得
- 記述式でさらに1回正解 → 記述式も習得済み
- その後、選択式で不正解 → 選択式だけ未習得に戻る
- 記述式の習得済み状態は維持される

不正解や「わからない」を選んだ場合、**該当する形式の連続正解数と習得状況のみ**リセットしてください。

### 画面表示

LEVEL・SECTIONの進捗は、選択式と記述式を別々の数値・進捗バーで表示してください。

単語一覧と詳細でも、各形式の習得状況を区別します。

単熟語Premium未購入者には記述式の機能をロック表示して構いませんが、過去に記録された記述式データを削除しないでください。

### 初回診断との関係

初回診断は選択式にだけ存在します。

診断で正解した項目は、診断を正常完了した時点で**選択式のみ即座に習得済み**にしてください。

記述式の習得状態には影響を与えません。

## 6. 通常練習

### 選択式

- 4択＋「わからない」
- 全件・未習得のみ・お気に入りのみ
- 固定番号順・ランダム順
- 問題数10・20・30・50・対象全件
- 時間制限なし
- 英語表示時の発音自動再生と再生ボタン
- 解答後は同じカード内に正誤・意味・例文・解説を表示
- 画面タップで次の問題へ進む
- 間違えた項目だけを、すべて習得済みになるまで再練習可能

正解の選択肢はランダムに配置し、ほかの選択肢も意味が重複しないようにしてください。

### Premium記述式

日本語の意味を表示し、対応する英語を入力させてください。

- 大文字・小文字は区別しない
- 前後の空白を無視
- 原則としてスペルの完全一致で採点
- 別解は教材データに明示的に登録した表記のみ許可
- 記述式の習得状態だけを更新

熟語では、英語の語数と**最初の単語の頭文字だけ**をヒントにしてください。

各単語に独立した入力欄を用意し、すべて正解した場合のみ正答とします。

正解後は英語の発音・例文・解説を表示できます。

## 7. 効果音システム【追加仕様】

アプリ全体にオリジナルの短い効果音を実装してください。

### 効果音の種類

1. **タップ音**：ボタン・選択肢・タブなどを操作したときの軽いクリック音
2. **正解音**：通常練習で正解したときの明るいチャイム
3. **不正解音**：通常練習で間違えたときの控えめな通知音
4. **合格音**：セクション試験・LEVEL卒業試験の合格演出
5. **時間切れ音**：必要に応じて短く中立的な通知音

### 実装ルール

- 効果音は短く、学習を邪魔しない音量
- 同じ音が重なりすぎないよう制御
- ボタンの二重タップによる連続再生を抑制
- 英語の発音音声と効果音は別管理
- 設定画面に「効果音 ON/OFF」を用意
- 英語の発音音声にも独立したON/OFF設定を用意
- 設定内容を保存
- Webブラウザの自動再生制限に対応
- 商用利用可能なオリジナル音源または適切にライセンスされた音源を使用

**習得判定試験では、各問題の回答直後に正解音・不正解音を鳴らさないでください。**

正誤は試験終了まで非公開です。

試験中は中立的なタップ音のみとし、合否に応じた効果音は結果画面で再生してください。

## 8. 初回診断・習得判定試験

### 問題数・合格条件

| 種類 | 問題数 | 合格 |
|---|---:|---:|
| 英単語 初回診断 | 100 | 95 |
| 英単語 セクション試験 | 100 | 95 |
| 英熟語 初回診断 | 50 | 48 |
| 英熟語 セクション試験 | 50 | 48 |
| 英単語 LEVEL卒業試験 | 100 | 95 |
| 英熟語 LEVEL卒業試験 | 100 | 95 |

選択式試験は**8択＋「わからない」**、1問10秒。

Premium記述式試験は1問30秒。

問題番号・選択肢は適切にランダム化してください。

### 試験中の動作

- 各問題表示時にタイマー開始
- 制限時間内の回答は自動的に次へ
- 時間切れ時は「時間切れ」と表示
- 時間切れ後は画面タップで次へ
- 一度回答した問題には戻れない
- 正誤・解説は全問完了まで非表示
- 各問題の正誤を音で知らせない

### 初回診断

初めてSECTIONに入った際に「受験」「スキップ」「戻る」を提示してください。

受験またはスキップの確定後は、初回診断の機会を再取得できません。戻る場合は機会を維持します。

完了した初回診断で正解した項目は、選択式のみ即座に習得済みとします。

合格点に達した場合は選択式のセクション合格も永久記録します。

### セクション試験の解放

**選択式試験：選択式の習得状況が全項目100%の場合だけ解放。**

**記述式試験：記述式の習得状況が全項目100%の場合だけ解放。**

英単語は100/100語、英熟語は50/50個。

選択式を全件習得しても、記述式試験は解放されません。その逆も同様です。

不合格後の再受験では、該当形式の習得状況を再び100%にする必要があります。

### LEVEL卒業試験

該当する教材種別と出題形式のセクション合格がすべて揃った場合のみ解放します。

選択式英単語、選択式英熟語、記述式英単語、記述式英熟語の**4系統を完全に独立**させてください。

各LEVELの対象セクションからなるべく均等に100問を選びます。

LEVEL試験に失敗した場合、該当するセクション合格が維持されていれば即再挑戦可能です。

### 試験の中断と確定処理

試験中の習得変更・連続正解数の変更は、完了まで仮状態として保持してください。

試験途中で終了・ページ再読み込み・中断した場合、その試験の変更を破棄し、開始直前の習得状態に戻してください。

中断した試験を途中から再開することはできません。

初回診断の受験権だけは開始後の中断でも消費します。

試験完了後、**該当する選択式または記述式の状態だけ**を確定更新してください。

過去の合格記録は消さないでください。

### 結果画面

- 得点と合否
- 間違えた問題一覧
- 全問題一覧
- 正解・回答・解説
- 間違えた項目だけを再練習

過去の試験結果は履歴として保存してください。

## 9. 称号

各LEVELの卒業試験の合格状況に応じて、次の称号を与えます。

- **SILVER**：選択式の英単語・英熟語のどちらか片方に合格
- **GOLD**：選択式の英単語・英熟語の両方に合格
- **DIAMOND**：GOLD達成に加えて、記述式の英単語・英熟語の両方にも合格

称号と試験合格記録は永久保持してください。

現在の選択式・記述式の習得数が減少しても、称号は取り消しません。

## 10. 長文演習

合計400題。各LEVELに100題。

各LEVELで次の10形式を10題ずつ収録します。

1. 内容一致
2. 語句空所補充
3. 文・節の空所補充
4. 主題・タイトル選択
5. 指示語の内容把握
6. 推論
7. 文挿入
8. 段落整序
9. 要約
10. 語句の意味推測

すべて4択。

1長文あたり3〜10問を、語数・難易度・問題形式に応じて個別設定してください。

### 演習画面

- 本文と設問の2タブ方式
- タブごとに独立したスクロール位置の保存
- 回答の保持・提出前の変更
- 経過時間・目安時間を常時表示
- 目安時間を超えても継続可能
- 時間超過による減点・強制終了なし
- 全設問提出後に一括採点

再挑戦は無制限です。

初回・最高・最新の得点と所要時間を保存してください。

同じ正答率の場合、短い所要時間を最高記録の比較条件とします。

### 長文解説

利用可能なすべての長文に以下を用意してください。

- 全文和訳
- 各設問の正答と根拠
- 不正解選択肢の説明
- 重要英文の構文解説

構文解説は解答提出後、**本文中の重要英文をタップして表示**してください。

S・V・O・Cなどを色分けし、節は `[ ]`、句などの修飾部分は `( )` で表し、矢印などで修飾関係を視覚化してください。

色だけでなく構文記号も併記してください。

解説の表示・非表示で本文のスクロール位置を失わないようにしてください。

### 無料で使える長文

各LEVELで好きな3長文を永久解放可能にします。

選択前に確認を表示し、確定後は変更できません。

無料解放した長文でも全文和訳・設問解説・構文解説をすべて利用できます。

長文Premiumまたは完全Premiumでは、全400題を解放します。

現在の習得総数は、不正解による減少も反映してください。

9. 長文演習の本文・設問タブと一括採点
10. 学習記録・検索
11. タップ・正解・不正解・合格の効果音
12. 端末内データ保存
13. Web版へのデプロイ

最初の動作確認には、英単語100語・英熟語50個・長文数題の検証用教材を用いてください。

ほかのLEVELや教材を後から追加できる構造にしてください。

### 必須テスト

- 選択式2連続正解で選択式のみ習得済みになる
- 記述式2連続正解で記述式のみ習得済みになる
- 一方の不正解が他方の習得状況を変更しない
- 選択式の初回診断が記述式の状態を変更しない
- 記述式試験は記述式全項目習得でのみ解放される
- 各形式の試験中断で変更が取り消される
- 合格記録と称号が永久に保持される
- 通常練習では正解・不正解の効果音が鳴る
- 試験中に正誤を知らせる効果音が鳴らない
- 効果音をOFFにしても英語発音を利用できる
- タブ切り替えで長文のスクロール位置が失われない
- 長文の目安時間を超えても回答を続けられる
- 学習記録がページ更新後も保持される
