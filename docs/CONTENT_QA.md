# 教材検査の範囲

## 自動検査できたもの

検証教材150件と追加草稿100語の安定ID・基本構造、新規100語の番号001〜100、必須文字列、許容表記、出典ID、重複。草稿はreview_required、humanReviewed=false、productionApproved=false。

正式教材検査の実装: ID重複、LEVEL/SECTIONの割当、番号の欠落・重複、100語/50熟語のSECTION数、見出しの正規化重複、メタデータ、出典の商用/再配布条件、校閲/承認フラグ。構造が正しくても意味の正確性を機械判定したことにはならない。

長文検査の実装: LEVEL・形式、3〜10問、各4つの異なる選択肢、有効な正答ID、各選択肢の解説、本文に存在する根拠、段落ごとの和訳、構文の文字位置・文字列・SVOC等の役割・関係ID。構文のoffsetは段落内Unicodeコードポイント単位のstart以上/end未満で、将来の描画時はArray.from(text)等で同じ単位を使う。Pythonの検査が英語の解析そのものを保証するものではない。

全量ゲートはLEVEL別3,900語・2,000熟語・400長文、およびLEVELごとに各10形式10題を検査。現状は不足のため失敗する。

## 人の確認が必要なもの

250項目すべての英語・訳文・IPA・語義・自然さ・書き取り問題の一意性・難易度・採否。公式リストの現在の利用条件、出典ごとの権利範囲、独自教材の商用公開前レビュー。長文は未制作なので校閲済み0題。

旧検証教材を仕様に合わせて機械的に難語へ置き換えていない。既存の学習履歴が別の語に移ることを防ぐため、IDを保護している。

## 制限

語形・意味まで含む重複の最終判断、4択の意味的な一意性、語彙選定の受験への有用性は、人手の校閲と実資料照合が必要。熟語の構文解析は候補検出段階。書類上の承認フラグだけで実際のレビューが行われたと見なさない。
